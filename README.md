# 🛍️ ShopNova – Modern E-Commerce Website

ShopNova is a modern, responsive e-commerce website built as a **Full Web Application Capstone Project** using HTML, CSS, and JavaScript.

The project demonstrates responsive UI design, dynamic product rendering, shopping cart functionality, LocalStorage, performance optimization, and mobile-friendly navigation.


## 📌 Features

* 🏠 Modern and responsive homepage
* 🛍️ Dynamic product listing
* 🛒 Add products to cart
* ➕ Increase/decrease product quantity
* 🗑️ Remove products from cart
* 💾 Cart data stored using LocalStorage
* 🔢 Dynamic cart item counter
* 💳 Mock checkout functionality
* 📱 Mobile responsive design
* ☰ Responsive navigation menu
* 📧 Newsletter subscription form
* ✨ Modern hover effects and animations
* ⚡ Optimized and lightweight frontend
* ♿ Accessibility-friendly design
* 🌐 Cross-browser compatible

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, responsive design and animations
* **JavaScript (ES6)** – Dynamic functionality
* **LocalStorage** – Persistent cart data
* **Google Fonts** – Inter font family
* **Font Awesome / Icons** – UI icons

### 1. Clone the repository

```bash

```

### 2. Open the project

```bash
cd shopnova-ecommerce
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, use the **Live Server extension in VS Code**.

## 🛒 How It Works

1. Visit the ShopNova homepage.
2. Browse available products.
3. Click **Add to Cart**.
4. Open the Cart page.
5. Change product quantities or remove products.
6. Proceed to checkout.
7. Complete the mock checkout process.

Cart information is stored in the browser using **LocalStorage**, so the cart remains available after refreshing the page.
